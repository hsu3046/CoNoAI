설정 › 진단에서 최근 30초를 저장하면 입력·처리 출력 WAV와 `diagnostics.json`이 한 폴더에 생긴다. 마이크 음성은 포함하지 않는다.

```bash
python3 scripts/find_clicks.py ~/Downloads/CoNo-diagnostic-...
```

폴더를 넘기면 양쪽 채널을 검사하고, JSON의 각 WAV 시작 프레임과 분리 오프셋으로 캡처 스트림 시각을 맞춘다. 입력·출력 WAV는 서로 다른 순간에 스냅샷하므로 같은 파일 초를 그대로 비교하면 안 된다. 입력에 가까운 후보가 있는 출력 후보와 출력에서만 관측된 후보를 구분한다. 일치 범위는 20ms이며, 샘플레이트 변환의 작은 지연을 포함한다.

예전처럼 WAV 경로를 여러 개 넘겨 각각 검사할 수도 있다. 이 경우 공통 시간축을 알 수 없으므로 파일 안의 시각만 표시한다. 오른쪽 채널에만 생긴 불연속도 검사한다.

후보는 주변 50ms 대비 큰 2차 차분이다. 드럼·자음·고음도 후보가 될 수 있어 클릭의 확정 판정이 아니다. WAV는 워커 입출력이고 키 조절·재생 렌더·실제 출력 장치보다 앞 단계이므로, 파일에 후보가 없다는 사실만으로 장치 이후 소리를 정상이라고 판단하지 않는다.

## 2026-10-03 확인

- 기존 코드의 90초 합성 신호를 48→44.1, 44.1→48, 44.1→96kHz로 변환했다. 고정 4,096프레임과 1~16,000프레임 가변 입력의 출력 길이·샘플 값이 일치했다. 워밍업 이후 최대 2차 차분은 각각 0.000782, 0.000660, 0.000166이었다. 이 입력에서는 리샘플러의 청크 경계 문제가 재현되지 않았다.
- 실제 MDX 모델과 1초 스텝 분리기를 거친 60초 합성 신호는 2,646,000프레임으로 길이가 보존됐고 원곡 경로의 최대 오차는 0이었다. 반주에 비유한 값은 없었으며 워밍업 이후 최대 2차 차분은 0.003768이었다. 실제 노래나 출력 장치에서의 무잡음을 보장하는 검사는 아니다.
- 반주·보컬·원곡과 가이드 볼륨은 기존에 분리 스텝 경계에서 즉시 교체되어 파형 단차를 만들었다. `SeparationMix`가 20ms 교차 혼합하며, 합성 입력의 0.8 단차가 한 샘플당 0.001 미만으로 분산됨을 검증했다. 전환 중 다른 선택, 반복 설정, 좌우 채널도 검사한다.
- 이 모드 전환 수정은 재생 중 아무 조작 없이 발생하던 간헐적 클릭 전체의 해결을 뜻하지 않는다. 해당 증상의 녹음·발생 시각·장치 조건이 필요하다.
