# 로컬 검증용 파일

© 2026 AIB Inc. (https://www.aib.vote) · GPL-3.0-or-later

- `score-v1.json`: 실제 노래 성적이 아닌 92점 테스트 기록. Mac/웹 백업 왕복 확인용.
- `lyrics-word-timing.lrc`, `lyrics-word-timing.ttml`: 같은 3줄의 자체 제작 테스트 문장과 단어 시각. 첫 줄은 1~4초, 둘째 줄은 5~8초, 셋째 줄은 9~12초다.
- `lyrics-line-timing.srt`: 같은 문장의 줄 단위 시각. 단어별 시각은 들어 있지 않다.

가사 파일은 현재 곡에 가져오거나 끌어다 놓아 확인한다. 실제 곡의 가사가 아니므로 확인 후 내 가사 파일을 삭제하면 온라인 가사로 돌아간다. 탭 편집 테스트에는 위 문장의 일반 텍스트를 붙여 넣는다. 테스트 문서를 실제 곡의 가사로 공개 게시하지 않는다.
