- 해결: 분리된 보컬의 16 ms 음정 프레임으로 음절 경계를 정렬 (AI 분리 모드 전용, 없으면 비례 근사).
  - 단위: 한글·가나·한자 1글자, 작은 가나·장음은 앞에 붙임, 영어는 단어(무게 = 모음 묶음 수)

  - 음절 안에서는 소리 내는 동안만 진행 (숨에서 멈춤). 표시는 글자 수 → 실제 글자 폭 비율로 환산.
