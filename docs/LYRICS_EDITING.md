## 파일 가져오기

설정 › 가사 › 내 가사 파일에서 파일을 선택하거나 끌어다 놓는다. 메인 무대의 가사 영역에도 파일 하나를 놓을 수 있다. 무대에서는 화면에 들리는 곡, 설정에서는 선택 당시의 곡에 붙인다. 비동기 작업 중 다른 곡으로 바뀌어도 새 곡의 가사를 덮지 않는다.

- **LRC / enhanced LRC**: 줄 시각과 제공된 단어 시각.
- **TTML**: 문장·단어·음절 시각. 마지막 단어 이후의 문장 종료까지 보존한다.
- **SRT**: 줄 시작과 종료. 한 cue 안의 여러 줄은 공백으로 합친다. 동시에 겹치는 cue는 한 줄 가사 화면에서 명확하게 표현할 수 없어 거부한다.
- **KRC**: 압축된 로컬 파일의 단어 시각. 원본 바이트는 JSON 안에 base64로 보존한다. 온라인 Kugou 연결은 하지 않는다.
- **QRC**: 로컬 바이너리·16진수 암호문·복호화된 XML/본문의 줄·단어 시각. 원본 바이트는 JSON 안에 base64로 보존한다. 온라인 QQ 연결은 하지 않는다.

LRC·TTML·SRT 텍스트는 UTF-8 또는 BOM이 있는 UTF-16을 받는다. 입력은 1 MB, 최종 가사는 4,000줄·한 줄 500자 이하이며 손상된 기존 저장 파일은 자동으로 덮어쓰지 않는다. 자세한 KRC·QRC 제한과 온라인 소스 상태는 [LYRICS_SOURCES.md](LYRICS_SOURCES.md)를 참조한다.

사용자 파일이 온라인 가사보다 우선한다. 자동 싱크는 적용하지 않고 사용자가 직접 미세조정할 수 있다. 내 가사 파일을 삭제하면 온라인 검색으로 돌아간다. [자체 제작 테스트 파일](fixtures/README.md)로 확인할 수 있다.

## Space로 줄 시각 기록하기

1. 곡을 선택한 상태에서 설정 › 가사 › **가사 직접 맞추기**를 연다.
2. 현재 일반 가사를 불러오거나 가사를 한 줄씩 붙여 넣고 **줄 시간 맞추기**를 누른다.
3. 곡을 재생하고 **기록 켜기**를 누른 뒤, 각 줄이 시작되는 순간 Space 또는 **줄 시각 기록**을 누른다. 키를 누르고 있어도 한 번만 기록한다.
4. 잘못 찍으면 **되돌리기**, 처음부터 다시 맞추려면 **시각 재설정**을 사용한다.
5. 모든 줄을 기록하면 **미리보기**, **LRC 내보내기**, **이 곡에 저장**을 사용할 수 있다.

기준은 CoNo에서 실제로 들리는 재생 위치다. 곡 변경·일시정지·탐색·언더런·출력 교체가 생기면 기록을 끈다. 재개 후 다시 기록을 켜야 하며 시각이 역전되는 입력은 거부한다. 저장 전에는 현재 적용된 가사를 바꾸지 않는다. 미저장 변경을 닫을 때는 버리기 확인을 받는다.

## 로컬 AI 가사 학습과 구간 초안

설정 › 가사 › **로컬 AI 가사 학습 · 실험**에서 **이 기기에서 가사 시각 학습**을 켠다. 기본값은 꺼짐이며 [선택형 모델](FORCED_ALIGNMENT_PLAN.md)이 포함된 앱에서 사용한다. AI 반주로 이미 들은 줄을 분석해 단어 시각을 저장하고 되감기·다음 재생에 반영한다. 제공된 원본 단어 시각이 있으면 그것을 우선한다.

기능을 켠 동안 최근 60초의 분리 보컬만 메모리에 보관한다. 음성은 외부로 보내거나 파일로 저장하지 않는다. 추가 메모리와 CPU를 사용하므로 기기 부하가 커지면 끌 수 있다. **학습한 단어 시각 모두 지우기…**는 자동 학습 기록만 삭제하며 직접 가져온 파일·탭 가사를 유지한다.

1. 같은 곡을 AI 반주로 잠시 듣고 **최근 구간 AI 가사 초안…**을 연다.
2. **현재 가사 불러오기** 또는 붙여넣기로 방금 들은 구간의 줄만 입력한다. 한 번에 최대 20초·512글자를 분석한다. 가사를 비워 두면 받아쓰기 초안을 만든다.
3. **최근 구간 줄 시각 맞추기** 또는 **최근 구간 받아쓰기**를 누른다. 취소·곡 전환·탐색 뒤에는 이전 결과를 적용하지 않는다. 실행 중 모델은 현재 분석을 마친 뒤 취소된다.
4. 결과의 시각 버튼으로 해당 줄을 다시 듣고 내용을 확인한다. **탭으로 다시 맞추기…**에서 원문·줄 시각을 수정하거나 다른 줄을 추가할 수 있다. **LRC 내보내기…**는 원본 단어 시각을 포함한다.
5. **이 구간을 내 가사로 저장…**은 확인 후 해당 곡의 로컬 가사를 이 구간으로 교체한다. 초안은 전체 곡이 아니므로 전체 가사를 만들려면 탭 편집에서 다른 줄을 추가한다. 선택했던 원본 파일과 온라인 가사는 삭제하지 않는다.

AI 초안을 생성하는 것만으로 현재 가사는 바뀌지 않는다. 반주 잔류·합창·긴 음·빠른 가사에서는 틀릴 수 있으므로 저장 전에 검토한다. 검증된 내부 신뢰도도 실제 정확도 확률은 아니다.

## LRCLIB 공개 공유

완성한 탭 가사에서 **LRCLIB에 공유…**를 누르면 공개할 곡 제목·가수·앨범·음원 전체 길이·가사와 시각을 검토한다. 공개 확인을 선택하고 **LRCLIB에 공개**를 눌렀을 때만 외부 전송을 시작한다. 이 기능은 로컬 점수 JSON 저장소나 향후 운영 DB 연결과 별개다.

게시 인증 계산은 백그라운드에서 최대 120초·1억 회 시도하고 취소할 수 있다. 전송 후 응답을 확인하지 못하면 결과가 미확정임을 알리며 자동 재시도하지 않는다. 중복 요청 전에 LRCLIB에서 해당 곡을 확인한다. 테스트 문장을 실제 곡 가사로 공개하지 않는다.

구현은 LRCLIB의 공식 서버 [게시 경로](https://github.com/tranxuanthang/lrclib/blob/main/server/src/routes/publish_lyrics.rs), [인증 요청](https://github.com/tranxuanthang/lrclib/blob/main/server/src/routes/request_challenge.rs), [SHA-256 검증](https://github.com/tranxuanthang/lrclib/blob/main/server/src/utils.rs)을 기준으로 했다. 자동 검증은 주입한 응답으로 성공·실패·취소·미확정 결과를 확인했으며, 개발 중 실제 가사를 게시하지 않았다.
