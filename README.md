# CoNo

스트리밍 앱(멜론·Apple Music·YouTube Music 등)에서 재생 중인 노래를 그대로 홈 노래방으로 바꾸는 macOS 앱.
파일을 받지 않고, 평소 쓰는 스트리밍 서비스를 그대로 활용한다.

> 상태: PoC ③ — 캡처 · 원본 음소거 · 지연 재생 + AI 보컬 분리 (UVR MDX-Net Karaoke 2, CoreML) + 음정 바 (SwiftF0)
